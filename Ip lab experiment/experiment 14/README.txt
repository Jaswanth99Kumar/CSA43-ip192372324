INTERNET PROGRAMMING LAB — EXPERIMENT 14
ReNewMarket — Second-hand Marketplace

HOW TO RUN
1. Extract the ZIP file.
2. Open the Experiment_14_ReNewMarket folder.
3. Double-click index.html to run in Chrome, Edge or Firefox.
4. Search/filter items, select an item and submit the form to see the sample result.

AIM
Browse used products, filter listings and post a demo listing.

EXPECTED OUTPUT
A responsive web page showing ReNewMarket, searchable demo items, a form, confirmation messages and browser-local saved records.

NOTE
This is a front-end educational demonstration. It uses localStorage and fictional/demo records. No real payments, bookings, voting, medical advice, or backend database are provided. Do not enter sensitive personal information. For production use, add secure server-side authentication, database validation and privacy protections.
